# 交付与发布

按主入口的风险等级选择必要检查。低风险本地第一版检查结构、边界和基本案例；生产使用再检查实际行为、脚本运行和信任。需要跨客户端或团队分发时执行所需目标编译、归档检查和安装模拟；存在上一版本时增加升级检查，共享注册时增加注册审计。高风险或外部发布再检查权限、回滚、审查记录和发布边界。

发布门禁只能阻止或警告，不能替缺失的外部证据。zip 归档不得含绝对路径、`..` 路径、秘密、凭据、原始遥测或临时文件。本地 .env 配置、虚拟环境和编辑器状态统一排除；有意分发的示例配置仍需秘密检查。安装模拟在临时目录解压，重新读取 frontmatter、manifest 和 interface；多 Skill 包验证全部 Router/子 Skill，不以任意首个入口代表整包。许可信息按用户指定的交付范围维护，不默认向 Skill 目录复制仓库许可证文件。版本变更说明兼容性、迁移步骤和建议的 semver bump。

分发当前源仓库中的 Ye 自身时，编译与归档会携带仓库的 canonical LICENSE，源 Skill 目录仍不存重复副本；用户创建的 Skill 不继承该许可证。分发其他代码时按其现有许可证保留必要声明。
