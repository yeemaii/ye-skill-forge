# 缺日志的排查示范

输入：10:00 发布 API 新版，10:03 登录超时。API 健康检查正常；数据库连接等待上升；新版实例日志暂不可得。用户只授权只读诊断，未授权回滚。

预期判断：发布相关性使新版连接使用变化值得检查，但并未证明根因。API 健康正常不排除数据库依赖。候选包括连接池配置变化和独立数据库拥塞，应分别检查版本配置差异、各版本连接数、数据库会话与等待原因。无权读取的资料保留缺口，不编造。

交付：证据表、按区分力排序的只读检查、假设支持与反证、待确认的回滚/缓解方案。实际回滚需要授权。未来验证应检查登录成功率与延迟、连接等待及其他数据库消费者，不能仅以 API 健康恢复宣称解决。
