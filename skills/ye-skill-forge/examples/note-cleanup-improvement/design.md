# 一个失败如何变成可复用改进

教学输入：旧规则要求“保留重要日期”，但没有更正和相对日期处理。会议记录先说周五、后明确更正为下周一，会议日期未知。

初始候选见 before/SKILL.example.md。可能出现的错误是保留两个互相矛盾的截止日期，或用运行当天计算绝对日期。这里只提出可复现假设，不声称观察到了模型失败。

改进采用最终明确更正、保留来源、相对日期不无依据换算。改进后的候选复用 ../note-cleanup/SKILL.example.md，避免维护两份相同入口。

evals/output/cases.json 固定原问题、原成功行为和未解决冲突。分别在新会话运行前后版本，将原始输出和判定放在本地 reports/；没有实际记录时结论保持“待验证”。不仅要修复更正问题，还要保留明确负责人/绝对日期的正常提取。
