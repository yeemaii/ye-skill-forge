# 从需求到设计

需求：研究者既要独立筛选来源，也要对已有来源表做综合；还要支持先筛选再综合。这些职责可以独立调用，因此使用家族，而不是仅因流程有两步就拆分。

Router 只决定路径与交接。筛选产生保留定位和排除原因的 records，综合消费同一结构。关键判断是可比性、原始出处与支持依据，不是链接数量。采用原始出处和来源依据字段，使可信度检查能实际交接；保留 unknown、excluded 与 duplicate，避免下一阶段因筛选而丢失证据限制。

不默认联网：用户提供的正文或已授权工具可读来源构成输入。来源不可访问时记录缺口。worked-example.md 展示跨阶段输入与结果；evals/output/cases.json 是业务行为计划，route_cases.json 是路由计划，均不声称已经实跑。
