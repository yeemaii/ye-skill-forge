# 会议纪要整理

## 目的
把会议记录整理成保留决定、行动项和未决问题的纪要。

## 何时使用
用于会议记录、通话转录或需要忠实整理的工作笔记。

## 输入
会议记录或转录；姓名和日期可能不完整。

## 工作流
1. 读取完整输入。
2. 去除重复内容，但不遗漏决定或约束。
3. 分开整理决定、行动项和未决问题。
4. 保留原文给出的负责人和日期；缺失值标为“未分配”或“未知”。
5. 检查每个行动项都能在输入中找到依据。

## 输出契约
返回 Markdown，并包含：摘要、决定、行动项、未决问题。

## 边界
- 不推断来源没有写出的负责人、截止日期或决定。
- 不把试探性想法当成已接受的决定。
- 未经请求不增加建议。

## 质量检查
- 每个行动项有来源支持，并有负责人或“未分配”。
- 决定保留重要条件和限制。
- 未解决事项继续出现在未决问题中。
