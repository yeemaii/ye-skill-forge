# 会议纪要整理

## 目的
把会议记录整理成保留决定、行动项和未决问题的纪要。

## 何时使用
用于会议记录、通话转录或需要忠实整理的工作笔记。

## 输入
会议记录或转录；姓名和日期可能不完整。没有正文时请求提供正文，不根据会议标题生成纪要。

## 工作流
1. 读取完整输入。
2. 去除重复内容，但不遗漏决定或约束。明确撤回或更正以最终确认内容为准，保留必要的变更说明；互相矛盾且未解决的内容列为未决问题。
3. 分开整理已确认决定、已接受行动项和未决问题。建议、问题和试探性想法不能仅因出现动作词就成为决定或任务。
4. 保留原文给出的负责人和日期；缺失值标为“未分配”或“未知”。相对日期仅在会议日期和时区明确时换算，否则保留原措辞并说明无法确定绝对日期。
5. 给决定和行动项保留时间戳、行号或简短原文依据，再逐项核对；无可靠定位时使用原文摘录，不编造定位。

## 输出契约
返回 Markdown，并包含：摘要、决定、行动项、未决问题。行动项写明任务、负责人、日期和依据；没有对应内容的栏目写“无明确记录”，不补写事项。具体输入与预期结果见 [worked-example.md](worked-example.md)，用于理解判断，不固定所有纪要的排版。

## 边界
- 不推断来源没有写出的负责人、截止日期或决定。
- 不把试探性想法当成已接受的决定。
- 未经请求不增加建议。

## 质量检查
- 每个行动项有来源支持，并有负责人或“未分配”。
- 决定保留重要条件和限制。
- 未解决事项继续出现在未决问题中。
